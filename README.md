# Eko Korean Beauty

Statički sajt spreman za GitHub Pages.

1. Napravi novi repozitorijum na GitHub-u i ubaci sve fajlove iz ovog foldera u root.
2. Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
3. Sajt će biti na https://<korisnik>.github.io/<repo>/

- index.html – početna
- shop.html – shop
